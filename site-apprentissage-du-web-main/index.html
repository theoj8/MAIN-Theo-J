Cours suivi

Concepts clés

Partie 1 - Découvrez le web et ses origines

Web

Service utilisant internet, permettant aux utilisateurs de faire des recherches.

Internet

Réseau permettant aux pc de communiquer entre eux.

Cloud

Permet de stocker des données en ligne, sans être stockée localement.

W3C

World Wide Web Consortium, organisme international qui définit les standards du web. Créé en 1994 par Tim Berners-Lee.

Partie 2 - Distinguez les langages du Web

Langages client

Language lu et interprété par le pc du client (le notre), comme le HTML, le CSS ou le JavaScript. Décris comment le site web doit s'afficher.

Navigateurs

Logiciel qui permet d'accéder à des sites web, de les afficher et d'intéragir avec eux

Langages serveur

Language lu et interprété par les serveurs, comme le PHP, le Java, le Pyhton,... Décris comment le site web doit se comporter.

Frameworks

"Boîte à outil" permettant aux développeurs de gagner du temps sur le code. Contient généralement du code préécrit, des modèles standardisés, ...

Bases de données

Serveur de stockage servant à enregistrer des informations, comme la liste des utilisateurs, les messages envoyés, ...

Site responsive

Site s'adaptant au format d'affichage de l'écran de l'utilisateur.

Application mobile

Logiciel conçu spécialement pour les téléphones et tablette. Permet d'effectuer des tâches similaires aux sites web.

Partie 3 - Découvrez le fonctionnement du réseau

Serveurs

Machines qui possèdent les sites web et les distribuent aux clients.

Adresse IP

Unique et lié à l'ordinateur du client, sert à identifier le pc.

Nom d'hôte et DNS

Le "nom" du site web, permet d'accéder aux sites facilement, sans avoir à connaître l'adresse IP de celui-ci.

Protocoles

Language utilisé par les machines (pc et serveurs), leurs permettant de communiquer entre elles.

Partie 4 - Identifiez les métiers du web

Développeurs

Ceux qui créer les sites internet. Peut aussi bien être en front-end (partie visuel), qu'être en back-end (partie techique)

Product Managers et chefs de projets

Ceux qui coordonnent la production et l'évolution du produit.

Designers

Ceux qui travaillent à rendre le site efficace et à rendre l'utilisation agrable. Peut être UX (user xp, partie technique) ou UI (user interface, partie visuel)

Testeurs

Ceux qui test le produit final pour garantir la qualité.

Techniciens informatique

Ceux qui assurent le bon fonctionnement du parc informatique.

Langages de développement web

HTML

Front-End

Squelette du site Web. Il définit la structure de base du contenu, comme les titres, les paragraphes, les images, etc.

CSS

Front-End

Permet de définir la partie visuel du site web.

JavaScript

Front-End

Permet d'ajouter des interactions.

PHP

Back-End

Permet de créer des sites interactifs.

Java

Back-End

Principalement utilisé pour la création d'application professionel.

Python

Back-End

Très utilisé de par sa puissance et son accessibilité, apprécié pour sa syntace simple et sa grande communauté.

C#

Back-End

Développé par Microsoft, très utilisé pour la création d'application grand publique.

SQL

Bases de données

Sert à gérer et interroger les bases de données.

Boîte à outils du développeur

  • IDE comme VS Code : Logiciel permettant d'écrir du code.
  • Github : Plateforme en ligne permettant de stocker partager et gérer du code source.
  • Librairies / bibliothèques : Plateforme en ligne regroupant du code préécrit, des modèles préfait afin de simplifier le travail du développeur.
  • Frameworks : Boîte à outil qui facilite et structure le développement d'applications, comme Djago (python), Laravel (PHP) ou React (JS).
